# Dr. Amin Salman — Modern Literary

A standalone responsive author website concept built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

The website opens at `/`. Run `npm run build` for a production build.

## Before launch

The source brief referenced cover artwork, a portrait, and video files that were not included with the provided attachment. The website clearly labels temporary placeholders. Add approved cover image paths and USD prices in `src/data/books.ts`, and supply the portrait, biography, video, and contact details. Cart and checkout are previews; connect a secure payment provider, shipping/tax rules, order processing, and approved privacy/terms copy before taking orders. Newsletter and contact delivery also need service connections.
